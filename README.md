## Drive Frontend

This is a frontend for a simple file manager / drive application.

### Tech stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS
- Bun (package manager / runtime)

### How to run

Install dependencies:

```bash
bun install
```

Start the dev server:

```bash
bun run dev
```

Then open http://localhost:3000 in your browser.
